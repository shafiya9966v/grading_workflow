# Assignment Grading Workflow: Synthetic Data Generator

A reproducible generator for synthetic data about an assignment and rubric-grading workflow: courses, learners, enrollments, assignments, rubrics, submissions, grades, feedback, resubmissions and appeals. It also injects labelled anomalies, validates the data, and proves reproducibility with a fixed seed.

All data is synthetic. No external datasets and no real personal data are used.

## What is produced

- CSV, JSON and SQL seed files for every table
- `ground_truth.csv`: the labelled anomalies (kept separate; never used as an input feature)
- A validation report in `reports/`
- A reproducibility report: two runs with the same seed, with row counts and checksums compared

## Fixed seed and reproducibility

The seed is `20261022`. Scale is a parameter, and `starter` and `full` use the same generator code. TODO: add the generated checksums from `reports/` here.

## Injected anomalies

1. A submission belongs to an unenrolled learner
2. A grade exceeds the rubric maximum
3. A late penalty is applied twice
4. An appeal changes a grade without an audit-history row

Each one is recorded in `ground_truth.csv` with its table, record ID and issue type.
